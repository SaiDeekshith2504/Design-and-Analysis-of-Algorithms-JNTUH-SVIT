# Unit I: Introduction and Divide and Conquer

This unit introduces the fundamental concepts of algorithm design and analysis.
It explains how to measure the performance of algorithms using time complexity,
space complexity, and asymptotic notations. It also introduces the divide-and-
conquer technique and its applications in searching, sorting, and matrix
multiplication.

## Unit Objectives

- Understand the meaning and importance of algorithms.
- Analyze the time and space requirements of an algorithm.
- Learn asymptotic notations used to express algorithm performance.
- Understand the divide-and-conquer design technique.
- Implement searching, sorting, and matrix multiplication algorithms.
- Compare algorithms based on their best, average, and worst-case performance.

## Topics Covered

### 1. Introduction and Performance Analysis

- Definition of an algorithm
- Characteristics of an algorithm
- Performance analysis
- Time complexity
- Space complexity
- Best-case, average-case, and worst-case analysis

### 2. Asymptotic Notations

- Big-O notation
- Omega notation
- Theta notation
- Little-o notation

### 3. Divide-and-Conquer Technique

- General method
- Binary search
- Quick sort
- Merge sort
- Strassen's matrix multiplication
